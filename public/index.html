AccessPatch

Working name. Checks a Shopify store the way a suing lawyer would, writes the missing image descriptions, and keeps a dated record of what was found and fixed.

$39/month — flat, one price. Weekly scan, AI alt text, dated fix report. No per-image charges.

Checking setup…

1. Scan a store

Paste any storefront address. The scan reads the homepage in a real browser and reports what it finds. Nothing is changed on the store.

2. What the scan found

Images missing alt text

Images with no alt attribute need a description. Images with empty alt (alt="") are decorative on purpose — they are counted separately and never filled in automatically.

3. Write the missing descriptions

An AI model reads each image and writes one plain sentence (about 125 characters). It never rewrites a description the merchant already wrote, and it never guesses — if it cannot tell what an image shows, it says so and the image stays in the review list.

4. Subscribe — $39/month

PayPal checkout (sandbox in this entry). Subscribing records the plan on this server; the weekly scan and auto-fix run once the app is connected to the store.

Fix report

Every scan and every fix, dated. Re-scan the same store after applying fixes and the report shows what is resolved, what is still there, and what is new.

What this does, plainly: it finds the accessibility issues plaintiffs cite most, writes the missing image descriptions, and keeps a dated record of what was found and fixed. What it does not do: it does not promise any legal outcome. No automated check can catch every issue — a person using a keyboard and a screen reader is the full check, and the report says so. Issues that need a human (contrast, keyboard navigation, forms) are listed with the exact element and how to fix them; the app does not change theme code.
